This means: when `_skip_conflict_scan=True`, `pre` is `{}` and the conflict scan in section 9 will find zero conflicts (every `existing = pre.get(api_name)` returns None, so the `if existing is not None and existing != sent_value:` branch never triggers — exactly the intent).

  Concretely, replace current lines 315-333 with:

  ```python
  # --- 7. GET activity (conflict scan) (D-14) -----------------------------
  pre: dict[str, Any] = {}
  if not _skip_conflict_scan:
      pre_get = await make_intervals_request(
          url=f"/activity/{activity_id}",
          api_key=api_key,
      )
      if isinstance(pre_get, dict) and "error" in pre_get:
          return (
              f"Error fetching activity for conflict scan: "
              f"{pre_get.get('message', 'Unknown error')}"
          )
      if isinstance(pre_get, list) and pre_get:
          pre = pre_get[0] if isinstance(pre_get[0], dict) else {}
      elif isinstance(pre_get, dict):
          pre = pre_get
      if not pre:
  ```

- **Section 9 (conflict scan, current lines 355-370):** keep the conflict-list construction logic OUTSIDE the skip flag — it's harmless when `pre = {}` because the loop body's `if existing is not None ...` is false for every key. But the **default-deny refusal** (the `if conflicts and not override:` branch that returns the error) must be wrapped: `if not _skip_conflict_scan and conflicts and not override:`. This protects the optimization: a freshly-POSTed activity has no conflicts, but defensively guard the refusal anyway in case `pre` somehow gets populated.

  Concretely, the refusal block becomes:

  ```python
  # --- 9. Conflict scan (D-14) --------------------------------------------
  conflicts: list[tuple[str, Any, Any]] = []
  for api_name, sent_value in supplied_pairs.items():
      existing = pre.get(api_name)
      if existing is not None and existing != sent_value:
          conflicts.append((api_name, existing, sent_value))

  if not _skip_conflict_scan and conflicts and not override:
      lines = [
          f"Error: activity {activity_id} already has values for fields below.",
          "Pass override=True to overwrite (an audit trail will be written).",
          "Conflicting fields:",
      ]
      for name, existing_val, sent in conflicts:
          lines.append(f"  {name}: {existing_val!r} (already set; sent: {sent!r})")
  ```
